# Multi-Factor Authentication (MFA) System

A secure Flask-based Multi-Factor Authentication (MFA) web application that protects user accounts through multiple layers of verification, including password authentication, image CAPTCHA verification, email OTP verification, and authenticator-based verification.

## Features

* Secure User Login
* Password Authentication
* Image CAPTCHA Verification
* Email OTP Verification
* Authenticator-Based Verification (TOTP)
* QR Code Generation for Authenticator Setup
* Password Reset via OTP
* Account Locking Mechanism
* Session Management
* SQLite Database Integration

---

## Authentication Flow

```text
User Login
    │
    ▼
Password Verification
    │
    ▼
Image CAPTCHA Verification
    │
    ▼
Email OTP Verification
    │
    ▼
Authenticator Verification
    │
    ▼
Access Granted
```

## Installation

### Clone the Repository

```bash
git clone https://github.com/kingsurya01/mfa_project.git
cd mfa_project
```

### Create a Virtual Environment

```bash
python -m venv venv
```

### Activate the Virtual Environment

**Windows**

```bash
venv\Scripts\activate
```

**Linux / macOS**

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
python main.py
```

Open your browser and navigate to:

```text
http://127.0.0.1:5000
```

## Security Features

### Password Authentication

Verifies registered user credentials before granting access.

### Image CAPTCHA Verification

Protects against:

* Automated bots
* Credential stuffing attacks
* Automated login attempts

### Email OTP Verification

Provides an additional authentication factor through one-time passwords sent to the registered email address.

### Authenticator Verification

Uses Time-Based One-Time Passwords (TOTP) generated by authenticator applications for enhanced security.

### Account Locking

Prevents repeated unauthorized login attempts and helps mitigate brute-force attacks.

### Session Management

Maintains secure user sessions and restricts unauthorized access to protected resources.

---

## Password Recovery

The system supports secure password recovery:

1. Enter registered email address
2. Receive OTP via email
3. Verify OTP
4. Reset password securely
